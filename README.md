Hi, this is my timers tool for RMC14. A customizable workspace designed for CIC roles <sub> *(cough cough Staff Officer)*</sub> to have on a secondary monitor.<br>
### Features
 - Customizable timer windows
   - Draggable and resizable
   - Option for an audio cue when timers run out
 - Decorate your workspace
   - Upload as many images as you want
   - Images can be dragged around the workspace
  - Notepad tool
    - Draggable and resizable
    - Changeable font size
  - Layout Saving
    - Save/Load buttons can be found in Extras (click the wrench icon)
    - Workspace persistence after closing the page or refreshing
    - Almost* everything is saved

  *<sub>The font size and contents of notepad windows are not saved. The Z-index of windows is not saved.</sub>
